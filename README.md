# Whisper AI 語音轉文字工具

本專案是一個本機 Streamlit 介面，將影片或音檔轉成字幕與文字檔。介面採用「加入待轉譯檔案 → 佇列與片段 → 專有名詞與取代規則 → 開始轉譯 → 結果暫存區」流程，可一次排入多個檔案批次轉譯，每個檔案都能單獨指定 A–B 範圍，輸出的字幕時間仍對應原始影片。支援三種辨識引擎：Breeze ASR 25、OpenAI Whisper 與 SenseVoice-small（FunASR）。

## 批次佇列與結果暫存區

- 第 1 步可一次選多個檔案，或在路徑模式貼上多行路徑（一行一個），按「加入佇列」排入。重複的檔案會被擋下並提示。
- 第三種輸入方式是「匯入現有字幕檔」：把以前轉好的 SRT／VTT 讀進來直接編輯，套用取代規則後存回原檔，不需要影片。時間碼原樣保留，只有文字會變。多行文字的字幕會被合併成一行。編碼會自動嘗試 UTF-8、cp950、GB18030、UTF-16。因為沒有音訊，逐段試聽不可用。
- 第 2 步列出佇列狀態（待轉譯／轉譯中／完成／失敗）。按「設定片段」可對該檔單獨圈選 A–B，預設是全片；設定完按「收起片段設定」。
- 第 4 步「開始轉譯」會依序處理所有待轉譯項目，單一檔案失敗不會中斷其餘檔案，失敗原因顯示在該列。完成的項目可按「重新轉譯」重跑。
- 第 5 步「結果暫存區」保留這個工作階段內的每一份結果，用下拉選單切換，隨時回來繼續編輯字幕與下載，互不影響。也可以一鍵把全部結果寫入 `outputs/`。
- 結果只存在記憶體中，重新整理瀏覽器會清空；要長期保存請先下載或寫出到 `outputs/`。

## 主要功能

- 影片或音訊載入後顯示簡化音訊波形，可快速看出長時間靜音。
- 在波形上水平拖曳即可套用 A–B，並支援 `HH:MM:SS.mmm` 毫秒時間碼。
- 可試聽選取起點 30 秒，確認內容後再執行辨識。
- 只擷取選定範圍交給辨識引擎，避免被前後長靜音干擾。
- SRT、VTT、TSV、JSON 的時間會自動加回 A 點，因此可直接套回原影片。
- 預設使用 OpenCC `s2twp`，將簡體轉為台灣繁體與常用詞後再輸出。
- 支援 TXT、SRT、VTT、TSV、JSON。
- 提供 Turbo、Medium、Large v3 等速度／品質預設。
- 專有名詞詞庫會存檔重複使用，用雙欄點擊決定本次啟用哪些詞。
- 字幕編輯器可搜尋、整批取代、標出偏快的段落，並逐段試聽原始音訊。
- 轉譯結果會保留在工作階段，可編輯字幕或新增輸出格式而不必重新推論。
- 顯示音訊擷取、模型載入、推論、後處理及 realtime 倍率。

## 專有名詞詞庫

第 3 步的「專有名詞詞庫」把人名、產品名與術語存進專案根目錄的 `glossary.json`，關掉程式也不會消失，不需要每次重打。

- 左欄是詞庫裡尚未啟用的詞，點一下加入本次轉譯，`🗑` 則是從詞庫永久刪除。
- 右欄是本次啟用的詞，點一下移出本次轉譯，但詞會留在詞庫裡。
- 新增時可一次貼多個詞，用 `、` `,` `;` `/` 或換行分隔；大小寫不同的同一個詞不會重複建立。
- 「開頭提示語句」用來把模型的語境定在中文，可降低中英夾雜時被誤翻成英文的機率。
- 啟用的詞會接在提示語句後面送給 Whisper。Whisper 只讀取提示語的結尾約 200 字，因此超過長度時介面會提醒你停用一些用不到的詞。

`glossary.json` 屬於個人資料，已列入 `.gitignore`。

## 常用取代規則

詞庫只是「提示」模型，效果有限，而且 Breeze 與 SenseVoice 根本不吃提示詞。**取代規則**則是在轉譯完成後直接改文字，因此不論用哪個引擎都一定會生效——固定會念錯、寫錯的詞用這個修最有效。

- 規則存在 `replacements.json`（已列入 `.gitignore`），一組是「尋找 → 取代為」，取代為留空即代表刪除該詞。
- 每條規則可以個別啟用／停用，不用時停用即可，不必刪掉。
- 啟用中的規則會在**每次轉譯完成時自動套用**，並在結果摘要顯示命中次數。
- 在字幕編輯器裡按「套用儲存的規則」可對現有結果重跑一次全部規則。
- 在字幕編輯器做單次取代時勾選「取代後存成常用規則」，就會把這組尋找／取代直接存進規則庫。
- 尋找是區分大小寫的，`Agent` 和 `agent` 會是兩條不同規則。

## 字幕編輯

轉譯完成後的「字幕編輯」分頁：

- 上方顯示段落數、總字數、偏快段落數與是否已修改。
- 「尋找與取代」和「套用篩選」各自是一個表單：在裡面打字或勾選**不會**觸發重繪，只有按下送出按鈕才會執行。這是刻意的——Streamlit 的輸入框預設在失焦時就送出並重跑整個面板，會讓版面在你還在填欄位時跳動、暫時少掉幾個控制項。
- 「尋找與取代」一次修正整份逐字稿裡重複出現的錯字，不受下方篩選影響。取代要求大小寫完全一致；若只是大小寫不同，送出後會明確告知有幾段接近但沒被取代。
- 勾「取代後存成常用規則」再送出，這組尋找／取代就會存進規則庫重複使用。
- 「套用篩選」只影響表格顯示。篩選不到任何段落時，表格會是空的，但試聽、還原、尋找取代等控制項都還在，並提供「清除篩選」一鍵復原。
- 「字/秒」欄位標示閱讀速度，超過每秒 9 個字通常代表斷句過長，可勾選「只顯示偏快的段落」集中處理。
- 選定段落編號後按「▶ 試聽此段」，會擷取該段前後各 0.15 秒的原始音訊，方便核對聽不清楚的地方。
- 「↩ 還原全部」可回到剛轉譯完的原始文字。
- 篩選狀態下的編輯一樣會寫回正確段落；切換篩選前請先按「儲存字幕修改」。
- 側欄「進階設定」會記住展開狀態，改完設定不會自己收起來。

## 辨識引擎

側欄「辨識引擎」可切換：

- **Breeze ASR 25（台灣華語＋中英夾雜推薦，預設）**：聯發科研究院從 Whisper-large-v2 微調的開源模型（Apache 2.0），針對台灣華語與中英夾雜優化。依官方數據，中英混語測試集 CSZS-zh-en 的 WER 由 29.49% 降到 13.01%（−56%），台灣華語 CommonVoice16-zh-TW 由 9.84% 降到 7.97%（−19%），且直接輸出繁體。語言選項與 Whisper 相同。首次使用會從 Hugging Face 下載約 3GB 模型（`MediaTek-Research/Breeze-ASR-25`），之後快取在 `%USERPROFILE%\.cache\huggingface`。GPU 上以 fp16 載入。

  這個引擎**不會**使用專有名詞詞庫。transformers v5 只要收到 `prompt_ids`，Whisper 的長音訊解碼就會在第一個時間窗結束後中止（實測 45 秒的音檔只轉出前 15 秒，其餘內容無聲丟棄），兩種 `prompt_condition_type` 與 `condition_on_prev_tokens` 的組合都一樣，且是否觸發跟提示詞長度有關，沒有安全的長度上限可設。丟掉三分之二的逐字稿遠比少了詞彙提示嚴重，因此提示詞只送給 Whisper 引擎。需要用詞庫校正專有名詞時請改用 Whisper。程式另外會比對轉出的字幕是否涵蓋整個選取範圍，若明顯偏短會出現警告。

- **Whisper（OpenAI）**：可選 Turbo／Medium／Large v3 等速度與品質預設，語言用下拉選擇（中文、自動偵測、英文、日文、韓文），並會套用第 3 步詞庫組出來的提示語。模型下載到專案內的 `models/` 資料夾。轉譯時固定使用 `task="transcribe"` 並保留 Whisper 內建的溫度回退機制。側欄「進階設定」裡的「防止英文翻譯漂移」預設開啟，會關掉 `condition_on_previous_text`：中英夾雜時 Whisper 偶爾會把某一段改成翻譯成英文，並透過上下文一路傳染到後面幾段，關掉段落間的關聯即可擋住這種連鎖效應，代價是跨段落用詞一致性略降。
- **SenseVoice-small（中英混合推薦）**：阿里 FunASR 的開源 ASR 模型，對中英夾雜語音的辨識效果比 Whisper 好、推論也快。語言可選「自動偵測」（中英混合建議）或指定中文／英文／粵語／日文／韓文。首次使用會從 Hugging Face 下載約 1GB 的模型與 VAD 模型（`FunAudioLLM/SenseVoiceSmall` + `funasr/fsmn-vad`），之後在本機（`%USERPROFILE%\.cache\huggingface`）快取。字幕分段依標點與最長時長／字數自動切段，時間碼取自模型的逐字時間戳記。

## 安裝

建議建立 Python 3.11 Conda 環境後安裝套件：

```powershell
conda create -n turnsrt python=3.11 -y
conda activate turnsrt
pip install -r requirements.txt
```

Whisper 另外需要系統已安裝 FFmpeg，並且 `ffmpeg` 可以在終端機中直接執行。

## 啟動

雙擊 `run_whisper.bat`。啟動器會優先從 PATH 自動尋找 Conda，再呼叫 `start_whisper.ps1` 檢查 Python 套件與 FFmpeg，最後啟動 Streamlit。若要固定使用上面的獨立環境，可先設定使用者環境變數 `WHISPER_CONDA_ENV=turnsrt`；未設定時會使用 Conda base 環境。

### 監聽位址

`run_whisper.bat` 裡的 `BIND_ADDRESS` 決定誰連得到這個服務：

- `tailscale`（預設）：只綁這台機器的 Tailscale 位址。同一個內網的其他電腦**連不到**，但你自己的裝置只要在 tailnet 上，不管人在哪裡都能連。啟動時會印出網址；注意這個模式下 `localhost:8501` 不會通，要用印出來的 Tailscale 網址（在本機也一樣可用）。
- 留空：綁所有介面，同一個內網的任何人都能開。
- 填一個 IP：只綁那個位址。

這個服務**沒有登入驗證**，而且「直接輸入電腦中的檔案路徑」模式能讀取這台電腦上的任意路徑。放到不信任的網路上等於把整台電腦的檔案開放出去，所以預設只走 Tailscale。

也可以手動執行：

```powershell
streamlit run whisper_app.py --server.maxUploadSize 5000
```

## 使用建議

- 大型影片建議使用「直接輸入電腦中的檔案路徑」，可避免瀏覽器上傳造成記憶體壓力。
- 在波形上由左往右拖曳即可套用 A–B；綠線代表開始、紅線代表結束。
- 要精確指定位置時，直接在下方輸入開始與結束時間，例如 `00:18:30.500`。
- 選段輸出的檔名會附上 A–B 範圍，但字幕內時間碼仍是原影片時間。
- 字幕預設**存回原始檔案旁邊**：影片 `D:\Videos\1222.mp4` 的字幕存成 `D:\Videos\1222.srt`；匯入的 `1222.srt` 存回它自己（覆蓋）。只有「拖曳上傳」的檔案沒有原始路徑可寫，才會存到 `outputs/<檔名>/`。
- 下載按鈕**不會**寫入上述位置，要寫檔請按「儲存到上述位置」。會覆蓋既有檔案時，儲存前會先列出被覆蓋的檔名。
- 選了 A–B 範圍時檔名會帶上時間範圍後綴，因此不會覆蓋整片的字幕。
- 如果不需要簡轉繁，可在側欄的「中文字體輸出」選擇「保留 Whisper 原文」。
- 中英夾雜的教學影片建議直接用預設的 Breeze ASR 25，它就是為這個情境訓練的，且輸出已是繁體，「中文字體輸出」可改選「保留原文」。
- 人名、品牌或術語請建進第 3 步的詞庫，提高固定詞彙的一致性（僅 Whisper 引擎適用，原因見上方引擎說明）。
- 中英夾雜的語音若用 Whisper 出現整段被翻成英文的情況，先確認側欄「防止英文翻譯漂移」有勾選，再把常出現的英文術語加進詞庫。
- 追求最快出稿可試 SenseVoice-small（語言選「自動偵測」）；需要 Whisper 原生行為或要靠詞庫校正時再切回 Whisper Large v3。
- 上傳模式可自行勾選是否在轉換完成後清除原始暫存檔；預設保留，方便再次調整範圍。
- Whisper 模型會下載到專案內的 `models/` 資料夾；SenseVoice 模型下載到使用者的 Hugging Face 快取。
- 同一時間只快取一個 Whisper 模型；切換模型時會淘汰舊項目，也可從側欄手動釋放 GPU 模型（會一併清除 SenseVoice）。
